Cómo usar tu propia cuenta de Google Gemini en Xabia Agent

BYOK — Bring Your Own Key. Conecta el plugin directamente con Google: las peticiones del chatbot van desde tu WordPress a la infraestructura de Google, sin pasar por el sistema de recargas de Xabia Cloud (#wallet).

En Xabia Agent tú tienes el control total. Si prefieres no utilizar recargas Xabia Cloud, puedes abonar el consumo directamente a Google — o aprovechar sus créditos gratuitos — manteniendo la clave en tu servidor.

Dos formas de conectar tu clave de Google

Recomendada · 95% usuarios

Opción 1: Google AI Studio (paso a paso)

Es la opción más rápida. No requiere configurar infraestructura en Google Cloud y se activa en menos de 2 minutos.

  1. Accede a Google AI Studio e inicia sesión con tu cuenta de Google.
  2. Haz clic en el botón destacado «Create API Key» (o «Crear clave de API»).
  3. Selecciona tu proyecto o deja que Google genere uno automático y pulsa «Create API key in new project».
  4. Copia la clave alfanumérica generada (formato AIza…).
  5. Ve al panel de WordPress → Xabia Agent (o Xabia LITE) → selecciona «Opción A: Tu propia clave de Google Gemini (BYOK)» y pega la clave. Guarda los ajustes.

Opción 2: Google Vertex AI (Enterprise)

Si tu empresa ya opera con Google Cloud Platform (GCP), requiere acuerdos de nivel de servicio (SLA) corporativos, facturación consolidada o residencia de datos en regiones específicas (ej. Europa-Oeste), puedes conectar Xabia Agent mediante Vertex AI.

Pasos para la integración con Vertex AI

  1. Crear o seleccionar proyecto: Accede a la Consola de Google Cloud y selecciona tu proyecto.
  2. Habilitar la API de Vertex AI: En el buscador de la consola, busca «Vertex AI API» y haz clic en Habilitar.
  3. Crear Cuenta de Servicio (Service Account):
    • Ve a IAM y Administración → Cuentas de servicio.
    • Crea una nueva cuenta con el rol Usuario de Vertex AI (Vertex AI User).
  4. Generar clave JSON: En la cuenta de servicio creada, ve a la pestaña Claves → Agregar clave → Crear clave nueva (formato JSON). El archivo .json se descargará en tu equipo.
  5. Configuración en Xabia Agent PRO: En los ajustes avanzados del plugin, selecciona el conector Vertex AI, introduce tu Project ID, selecciona la región (ej. europe-west1) y carga el contenido del archivo JSON.
