Regla de oro: el shortcode [xabia_agent] es el enchufe. La pestaña Apariencia es el molde. El mismo shortcode produce un chat embebido, un tótem o una pantalla dedicada según la tarjeta que elija. El lanzador [xabia_launcher] es otra pieza: solo el avatar/botón; el panel se abre al hacer clic.

1 Burbuja en todo el sitio

Sin shortcode. Apariencia → Web adaptable → activar «Mostrar en el sitio sin shortcode».

2 Chat en una página

Pegue [xabia_agent id="…"] en el editor (o un widget Shortcode de Elementor).

3 Avatar en el hero

Pegue [xabia_launcher id="…"] (alias: [xabia_avatar]). Al clic, abre el panel.

4 Tótem / quiosco

Elija tótem o pantalla en Apariencia y use el mismo [xabia_agent] o la URL /xabia-box/.

Burbuja nativa

Sin shortcode

Apariencia: Web adaptable + «Mostrar en el sitio sin shortcode».

Resultado: avatar fijo en una esquina. Al clic, se abre el panel (flotante, modal o pantalla completa, según el ajuste del panel).

Chat embebido

Shortcode chat
[xabia_agent id="mi-agente"]

Resultado: una caja de chat dentro de la página (columna, landing, ficha). El visitante escribe ahí; no aparece avatar flotante por este shortcode.

Lanzador / avatar

Botón incrustado
[xabia_launcher id="mi-agente" size="lg"]

Alias: [xabia_avatar id="mi-agente"]. Tamaño: sm md lg xl, píxeles (280) o porcentaje (42%). Alineación: align="center|left|right".

Resultado: solo el avatar/botón en ese punto. Al clic, se abre el panel del agente (no inserta el chat en el flujo de la página).

Tótem o pantalla

Mismo shortcode

Apariencia: Tótem transparente o Pantalla (vertical / horizontal). Fondo transparente = cristal/escaparate; fondo sólido = kiosko.

[xabia_agent id="mi-agente"]

Resultado: pantalla completa, avatar parlante + chat en dos zonas. El shortcode no cambia; cambia el molde de Apariencia.

Ruta /xabia-box/ (Smart QR y quiosco)

Sin pegar shortcode en una página
https://su-dominio.com/xabia-box/?x_project=mi-agente

Opcional, anclado a un ente (túnel): ?x_project=mi-agente&ente_id=sala-2

Resultado: la misma experiencia de tótem/pantalla a pantalla completa, sin menú de WordPress ni avatar flotante de sitio. Ideal para tablet de recepción, QR o monitor dedicado. Tras instalar o actualizar, visite Ajustes → Enlaces permanentes → Guardar.
