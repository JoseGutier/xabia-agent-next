Golden rule: the shortcode [xabia_agent] is the plug. The Appearance tab is the mould. The same shortcode yields an embedded chat, a totem or a dedicated screen — depending on the card you pick. The launcher [xabia_launcher] is a different piece: only the avatar/button; the panel opens on click.

1 Site-wide bubble

No shortcode. Appearance → Adaptive web → enable “Show on the site without shortcode”.

2 Chat on a page

Paste [xabia_agent id="…"] in the editor (or an Elementor Shortcode widget).

3 Avatar in the hero

Paste [xabia_launcher id="…"] (alias: [xabia_avatar]). On click, it opens the panel.

4 Totem / kiosk

Pick totem or screen in Appearance and use the same [xabia_agent] or the URL /xabia-box/.

Native bubble

No shortcode

Appearance: Adaptive web + “Show on the site without shortcode”.

Result: a fixed avatar in a corner. On click, the panel opens (floating, modal or full screen, according to the panel setting).

Embedded chat

Chat shortcode
[xabia_agent id="mi-agente"]

Result: a chat box inside the page (column, landing, product page). The visitor types there; this shortcode does not add a floating avatar.

Launcher / avatar

Inline button
[xabia_launcher id="mi-agente" size="lg"]

Alias: [xabia_avatar id="mi-agente"]. Size: sm md lg xl, pixels (280) or percent (42%). Alignment: align="center|left|right".

Result: only the avatar/button at that spot. On click, the agent panel opens (it does not insert the chat into the page flow).

Totem or screen

Same shortcode

Appearance: Transparent totem or Screen (vertical / horizontal). Transparent background = glass/window; solid background = kiosk.

[xabia_agent id="mi-agente"]

Result: full screen, talking avatar + chat in two zones. The shortcode stays the same; the Appearance mould changes.

/xabia-box/ route (Smart QR and kiosk)

No shortcode on a page
https://su-dominio.com/xabia-box/?x_project=mi-agente

Optional, pinned to an entity (tunnel): ?x_project=mi-agente&ente_id=sala-2

Result: the same full-screen totem/screen experience, without the WordPress menu or the site-wide floating avatar. Ideal for a reception tablet, QR or dedicated monitor. After install or update, visit Settings → Permalinks → Save.
