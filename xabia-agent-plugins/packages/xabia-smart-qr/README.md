# Obsoleto — no empaquetar

**Smart QR no es un addon ni un producto separado.**

La funcionalidad vive dentro de **Xabia Agent Core**:

- `packages/xabia-agent-core/core/class-xabia-smart-qr.php`
- `packages/xabia-agent-core/addons/xabia-qr/`

No generar ZIP, no publicar en `/downloads`, no crear benefit Polar.

Documentación: `documentation/manual-usuario-xabia-smart-qr.md` (módulo del Core).

Esta carpeta se conserva vacía a propósito para evitar que scripts antiguos busquen un plugin `xabia-smart-qr` y lo traten como producto.
